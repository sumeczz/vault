# Roadmap — Abyssbound

## Milník 0 — Projektový základ
- [x] Základní složky a projektové dokumenty.
- [x] Canvas scéna s kamerou sledující hráče.
- [x] Pohyb, útok, úskok a plošná schopnost.
- [x] Jednoduchá AI, zdraví, XP a levelování.
- [ ] Ověřit závislosti a produkční build na pracovním počítači.

Akceptace: dev server spustí prototyp; hráč se pohybuje a bojuje; kamera zůstává v hranicích světa.

## Milník 1 — Ovládání a boj
- [ ] Ošetřit ztrátu fokusu a uvolnění kláves.
- [ ] Směrové útoky s hitboxy místo kruhového zásahu.
- [ ] Telegraphy nepřátel, stagger a lepší feedback zásahu.
- [ ] Zvukové události, pauza, restart a nastavení hlasitosti.
- [ ] Ověřit ovládání na mobilu a desktopu.

## Milník 2 — Dungeon a výpravy
- [ ] Generovat místnosti podle seedu.
- [ ] Propojit místnosti a zajistit dosažitelnost cíle.
- [ ] Přidat truhly, pasti, obchodníka a elitní místnosti.
- [ ] Správce výpravy včetně vítězství, smrti a extrakce.

## Milník 3 — RPG progrese
- [ ] Inventář a datově definované předměty.
- [ ] Třídy zbraní s odlišným dosahem a tempem.
- [ ] Artefakty se synergiemi a raritami.
- [ ] Útočiště a trvalé odemykání.
- [ ] Lokální ukládání s verzováním dat.

## Milník 4 — Obsah a polish
- [ ] Originální vizuální assety a animace.
- [ ] Boss s více fázemi a čitelnými signály.
- [ ] Vyvážení obtížnosti a ekonomiky.
- [ ] Profilace výkonu a testování mobilních displejů.
- [ ] Automatizovaná kontrola buildu v CI.

Po každém milníku ověřit skutečné chování prototypu, zaznamenat výsledek a teprve potom pokračovat. Neoznačovat neotestované funkce jako hotové.
